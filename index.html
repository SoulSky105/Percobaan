🗄️ Database (tempat menyimpan log online)

Mode Lokal: data hanya tersimpan di perangkat ini (localStorage). Untuk log online lintas-HP, pilih Supabase atau Google Sheets.
📄 Cara setup Supabase (klik) 

          
1. Buat project gratis di supabase.com → SQL Editor → tempel kode di atas → Run.
2. Settings → API → salin Project URL & anon public key ke kolom di atas.
3. Klik "Simpan Konfigurasi". Selesai — log langsung online.

        

        

          📄 Cara setup Google Sheets (klik)
          
1. Buat Spreadsheet baru di Google.
2. Menu Extensions → Apps Script → hapus isi → tempel file Code.gs (ada di folder ini).
3. Deploy → New deployment → Web app → Execute as Me, Who has access Anyone.
4. Salin URL …/exec ke kolom di atas → Simpan.
